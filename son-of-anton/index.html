🔐 Son of Anton — Encryption Suite

Named after Anton/Gavin Belson's encryption system from Silicon Valley. This suite integrates all cryptographic modules from the PiedPiper project into a unified web toolkit.
AES-128
Advanced Encryption Standard with 128-bit keys. SubBytes, ShiftRows, MixColumns, AddRoundKey — 10 rounds of substitution-permutation network.
DES
Data Encryption Standard. Feistel network with 16 rounds, 56-bit key, S-box substitution, permutation.
RSA
Rivest-Shamir-Adleman public-key cryptosystem. Modular exponentiation, prime factorization security.
CA-Password
Cellular Automaton PRNG encryption using Wolfram's Rule 150. XOR-based stream cipher with deadlock-free random generation.
SHA-512
Secure Hash Algorithm 512-bit. Merkle-Damgård construction with 80 rounds of compression.
PP_SSH
Cellular Automaton encrypted SSH protocol. Encrypted shell with CA-PRG keystream, Ack protocol, multi-client server.

⚡ Built on the cryptographic foundations of Varul Srivastava, Ashwin Mittal, Shivang Gupta, Akshett Rai Jindal, Keshav Bansal, Zishan Kazi

CA-Password Encryption

Cellular Automaton PRNG-based stream cipher. Uses Wolfram's Rule 150 on a 2D cellular automaton grid to generate a pseudo-random keystream, XOR'd with plaintext. Based on the CA_Password_Protect module.
Click Encrypt or Decrypt

SHA-512 Hashing

Secure Hash Algorithm 512-bit. Merkle-Damgård construction. 80-round compression function with bitwise operations: majority, conditional, rotate, and modular addition. Cellular Automaton optimized variant also available.
Click SHA-512 or CA-SHA

PP_SSH Protocol

Cellular Automaton encrypted SSH protocol. Uses CA-PRG for command encryption/decryption over TCP sockets. Multi-client server with Ack protocol, encrypted shell execution, and exit handshake.
Click to encrypt/decrypt a PP_SSH command
