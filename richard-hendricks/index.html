Huffman Static
Optimal prefix coding. Builds a frequency tree, assigns shortest codes to most frequent symbols. O(n log n) tree construction.
Huffman Adaptive
Dynamic Huffman coding. Updates tree in real-time as data streams. No two-pass requirement.
Arithmetic Coding
Fractional bit encoding. Maps entire message to a single number in [0,1). Superior compression ratios vs Huffman.
BWT + RLE
Burrows-Wheeler Transform + Run-Length Encoding. BWT groups similar characters, RLE compresses runs.
JPEG Compression
Discrete Cosine Transform + quantization. Chroma subsampling, zigzag scanning, Huffman coding of coefficients.
K-means Compression
Color quantization via K-means clustering. Reduces color palette to K colors, maps each pixel to nearest centroid.
PBIC
Patch-Based Image Compression. Divides image into patches, finds similar patches, encodes differences.

Huffman Static Coding

Optimal prefix code. Builds a min-heap priority queue from character frequencies, constructs a binary tree, assigns unique binary codes where most frequent characters get shortest codes.
Click Compress or Decompress

Arithmetic Coding

Fractional bit encoding. Assigns a sub-interval of [0,1) to each symbol proportional to frequency. Encodes entire message as a single floating-point number in the final interval.
Click Compress or Decompress

Burrows-Wheeler Transform + RLE

BWT reorders characters to group identical characters. RLE then compresses runs. BWT is reversible, used in bzip2. Combined with Move-to-Front transform for better RLE.
Click BWT Transform, Inverse, or BWT+RLE Compress

JPEG-like Compression

Discrete Cosine Transform (DCT) on 8x8 blocks, quantization with quality factor, zigzag scanning, run-length encoding. Chroma subsampling for color images.
Click DCT Compress or Decompress

K-means Color Quantization

K-means clustering for color palette reduction. Groups similar pixel colors into K clusters. Each pixel is replaced by its nearest centroid. Tunable K value for compression ratio.
Click Quantize Colors

Patch-Based Image Compression

PBIC divides an image into overlapping patches, finds similar patches within a search window, encodes the difference between patches. Efficient for textures and repeated patterns.
